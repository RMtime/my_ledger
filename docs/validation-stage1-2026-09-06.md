# 阶段 1 验证记录（2026-09-06）

## 自动检查

- 服务层回归覆盖日期别名、付款方式、分类、搜索和可退款余额筛选。
- 录入状态机单测覆盖确认成功后废弃幂等键、保存并继续生成新键，以及已知拒绝/网络结果不确定时保留原键。
- `npm run check` 必须在阶段提交前通过。

## 手机尺寸浏览器验收

使用 390×844 视口、隔离的 `/tmp` SQLite 和 `LOCAL_DEV_AUTH=true` 验证：

- 普通保存进入完成页，只能通过“再记一笔”开始新草稿；
- 35 条合成流水显示“加载更多”，加载后完整显示后续记录；
- 搜索由服务端返回目标流水，旧页面请求会在筛选变化时取消；
- 编辑面板可修改金额、币种和付款方式，列表立即显示 `CNY 15.00 · 刷卡`；
- 退款使用可退款消费选择器，保存并继续后金额清空且类型恢复为支出。

测试只使用合成数据。未连接真实 Supabase、生产数据库或外部服务。
